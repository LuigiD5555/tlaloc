# Change Control — Tlaloc 6.0.0-alpha.13

Status: `EXPERIMENTAL_SEARCH_MACHINERY`

## Purpose

Add an evidence-driven search layer for candidate improvements to Origami's **single canonical visual profile**, including Master Prompt mutations, without creating a private aesthetic per document.

## Added

- `tlaloc.origami-visual-search.r0` candidate/evidence contract;
- candidate mutation families: `PROMPT`, `CHANNEL_ROLE`, `PRIMITIVE`, `LAYOUT`, `REDUNDANCY`, `COLOR_USAGE`, `NUMERIC_STRUCTURE`, `TEMPORAL_STRUCTURE`;
- numeric/mathematical candidates such as prime-derived spacing, modular patterns, factorization structures and periodic density;
- deterministic hard gates for semantic roundtrip, routing/evidence, UNKNOWN discipline, active-context budget, carrier size and `FALSE_EXACT=0`;
- real-model/trial minimums for perception-affecting candidates;
- weighted candidate ranking after hard gates;
- deterministic tournament and `tlaloc-visual-search` CLI;
- operational Fixed Carrier prompt aligned with Origami's canonical-profile/ROSETTA rule.

## Authority

```text
Tlaloc
  searches / mutates / benchmarks / recommends

Origami
  validates semantic + visual contract

Tonal
  composes exact revisions and promotes stack/profile support
```

The tournament output is recommendation only. It cannot alter Origami's canonical visual profile directly.

## Hard boundaries

```text
ONE DOCUMENT != ONE NEW AESTHETIC
CANDIDATE != CANONICAL PROFILE
VISUALLY INTERESTING != MEASURABLY BETTER
SEMANTIC ROUNDTRIP MUST NOT REGRESS
UNKNOWN DISCIPLINE MUST NOT REGRESS
FALSE_EXACT = 0
TLALOC RECOMMENDS / ORIGAMI VALIDATES / TONAL PROMOTES
```
