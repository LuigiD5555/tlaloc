# Tlaloc project workflow

1. Change Tlaloc on a branch and open a PR.
2. Gatekeeper classifies OWNER or EXTERNAL.
3. Run Tlaloc verification; external work additionally requires owner approval.
4. Promote Tlaloc.
5. In Tonal, update the exact Tlaloc pin and run full-stack verification/snapshot before distributing the new composition.

Shared Git/repository and provenance skills belong to Tonal. Tlaloc-specific behavior, Tlaloque and release guidance remains owned here.
