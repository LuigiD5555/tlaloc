# Distillation under Architecture R2

Tlaloc distillation means reducing demonstrated behavior into a smaller, more reliable or cheaper reusable representation.

It is not synonymous with prompt distillation.

## Candidate targets

```text
deterministic implementation
Machine/state machine
tool wrapper
Shponglese motif/program
prompt/policy
small specialized model
probabilistic Tlaloque
hybrid capability
```

Selection among targets should be evidence-driven.

## Evaluation dimensions

- behavioral fidelity;
- held-out reliability;
- competence envelope;
- verification coverage;
- runtime cost;
- model calls;
- latency;
- implementation/representation complexity;
- portability where relevant;
- reuse potential.

A more compact artifact that silently narrows behavior is not a successful distillation unless the narrowed competence envelope is explicitly intended and declared.
