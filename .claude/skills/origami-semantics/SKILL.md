# Origami integration discipline

Keep Origami semantics owned by Origami, not by Tlaloc.

## Current coherent-state profile

Distinguish `determinate`, `superposed`, `coupled`, and `observed` state kinds. Preserve explicit observation authority, interference/cancellation semantics, and the distinction between absence, unknown, inhibited, and zero-amplitude cancellation.

Treat the quantum-inspired profile as one Origami representation mode, not as a claim of physical quantum computation and not as the total scope of Origami.

## Integration rule

Tlaloc may consume Origami schemas, semantics and deterministic reference behavior to build evaluation fixtures. If a Tlaloc change requires altering an Origami law, stop and classify it as an Origami-owned change with an independent version decision.

## Perceptual-channel contract

Origami `6.0.0-alpha.2` introduced `origami.perceptual-channels.r0`; current Origami `6.0.0-alpha.3` preserves that contract and reconciles project hierarchy. The contract defines: spatial, interference, depth, temporal and emergent channels. Keep perceptual availability (`latent`, `motion-bound`, `phase-bound`, `stereo-bound`, `revealed`, `decayed`) separate from coherent-state kinds.

Know the upstream operation names `MOIRE`, `PHASE_SHIFT`, `STEREO_BIND`, `PARALLAX_RESOLVE`, `KINETIC_REVEAL`, `TEMPORAL_INTEGRATE`, and `TEMPORAL_DECAY`, but do not claim Tlaloc can execute/evaluate them until executable reference fixtures and tests exist. In particular, preserve `LATENT_IS_NOT_ABSENT`: failure to reveal a motion-bound percept in one static frame is not proof of absence.

## Project hierarchy

Treat OHF/R3.10-LAB, DVR/PSS, Glyph Calculus, SAFE_MICRO_ISA and Context SIMD as an Origami research track, not as the complete Origami language. Tlaloc may consume core Origami contracts or profile-specific OHF evidence without collapsing those scopes.
